# Фронтенд часть приложения "Movie Critics"

Архитектурный дизайн проекта основан на методологиях **Feature-Sliced Design** и **Atomic Design**.  
Структура проекта организована по папкам, чтобы обеспечить логическое разделение кода, упрощение сопровождения и повторное использование компонентов.

## Структура папок

### `app`

-   Хранит глобальные стили, типы и конфигурацию `store`.

### `pages`

-   Содержит компоненты для цельных страниц, которые объединяют видимые элементы и пользовательскую логику в рамках отдельных маршрутов.

### `widgets`

-   Представляют крупные, самодостаточные элементы интерфейса, реализующие отдельные пользовательские сценарии.

### `features`

-   Включают повторно используемые модули, реализующие функциональные возможности.

### `shared`

-   Хранит переиспользуемые элементы, независимые от бизнес-логики: компоненты загрузки и ошибки, хуки и др.

---

## Особенности структуры папок `widgets` и `features`

Каждая из них разделяется на сегменты:

-   **`hooks`**: кастомные хуки, используемые внутри данного модуля.
-   **`ui`**: набор компонентов, из которых состоят элементы модуля.
    -   Компоненты в папке `ui` организованы по аналогичной сегментной структуре.

## Как использовать

### Установка зависимостей

Для начала установите все необходимые зависимости, выполнив следующую команду:  
`npm install`

### Запуск приложения

Чтобы запустить приложение в режиме разработки, выполните:  
`npm run dev`

### Тестирование

#### Юнит-тесты

Для запуска юнит-тестов используйте следующую команду:  
`npm run test`

#### Интеграционные тесты

Для запуска интеграционных тестов выполните:  
`npm run integration`
