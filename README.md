## О проекте

Приложение *"Movie Critics"* представляет собой платформу для:  
- поиска информации о фильмах,  
- их обсуждения,  
- создания персонализированных подборок фильмов,  
- обмена мнениями с другими пользователями.  

---

## Функциональные возможности

### Пользовательский функционал
- Регистрация  
- Авторизация  

### Работа с фильмами
- Просмотр информации о фильмах:  
  - название,  
  - оригинальное название,  
  - жанры,  
  - продолжительность,  
  - и другие параметры.  
- Выставление оценок  
- Оставление комментариев  

### Работа с подборками
- Создание подборок фильмов  
- Добавление фильмов в подборку  
- Удаление фильмов из подборок  
- Изменение видимости подборок  
- Удаление подборок
